# Schema Studio

The authenticated `/schema` route provides snapshot selection, extraction requests, overview, filtered/paginated table browsing, ERD layouts, inspectors, source excerpts, lineage evidence, comparison and downloads. Workspace changes remount state. API responses are validated with shared contracts, and server-side authorization remains authoritative.

The diagram is bounded to 100 tables and eleven visible columns per table; full field/constraint details remain available through the inspector and complete JSON/Markdown exports. Solid and dashed relationship styles distinguish declared/resolved relationships from inference. Unsupported application-lineage steps remain explicitly unresolved.
